# La Previa

Juego de fiesta en el navegador para jugar con amigos desde un solo móvil: yo nunca, quién es más probable, retos y verdades. Las cartas usan los nombres de los jugadores y tienen un modo sin alcohol.

Sitio: https://adrianezd.github.io/la-previa/

Las cartas están en `cartas.js`. `{A}` y `{B}` son jugadores al azar y `{T}` es el castigo (tragos o sentadillas).
